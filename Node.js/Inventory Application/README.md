# 🛍️ Store CRUD Application

A small **Store Management Application** built to practice and strengthen my understanding of **CRUD operations**.

This project was a great opportunity to put what I learned into practice by building a simple store where products can be managed through the complete CRUD lifecycle.

## ✨ Features

* ➕ **Create** — Add new products to the store.
* 👀 **Read** — View existing products and their information.
* ✏️ **Update** — Edit and update product information.
* 🗑️ **Delete** — Remove products from the store.

## 🎯 Project Purpose

The main goal of this project was to test my skills and understanding of the basic **CRUD operations** and how they work together in a real application.

Building this project helped me practice working with data, handling requests, creating routes, and connecting the different parts of a web application together.

## 💭 What I Learned

Through this project, I gained more experience with:

* CRUD operations
* Routing and HTTP methods
* Handling forms and user input
* Working with a database
* Organizing an application structure
* Debugging and solving development problems
